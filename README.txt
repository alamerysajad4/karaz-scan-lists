ماسح القوائم — تطبيق تلفون مجاني (بدون Claude وبدون سيرفر)
=========================================================

الرفع على Vercel (نفس طريقة تطبيق دينار):
1. GitHub ← New repository ← اسمه مثلاً scan-lists ← Create.
2. «uploading an existing file» ← اسحب كل ملفات هذا المجلد (مو المجلد نفسه) ← Commit.
3. vercel.com ← Add New ← Project ← اختار scan-lists ← Deploy (ما يحتاج أي إعدادات).
4. يطلع رابط مثل https://scan-lists.vercel.app ← افتحه بالتلفون ← «إضافة إلى الشاشة الرئيسية».

الاستعمال:
- «استيراد قائمة»: ملف Excel (.xlsx) أو CSV. لازم يكون بيه عمود اسمه «اسم المادة» أو «الاسم» أو «التفاصيل».
  إذا ماكو عمود «الباركود» التطبيق يضيفه.
- اضغط «امسح الباركود» جنب المادة، أو «امسح التالي» ← وجّه الكاميرا على الباركود ← ينقرى وحده (صوت + اهتزاز).
  إذا «انتقل للمادة اللي بعدها وحده» مفعّل، تكمل مسح المواد ورا بعض بدون ما تسد الكاميرا.
  إذا مسحت باركود مسجل لمادة ثانية، التطبيق ينبهك وما يحفظه.
- لكل مادة: «عدد القطع بالكرتون» و«سعر البيع» تكتبهن بالتلفون.
- بعد ما ينقرى الباركود يطلع باركود حقيقي مرسوم. «⛶ القارئ» يعرضه بكل الشاشة حتى تدقه بقارئ الحاسبة.
- ✗ = المادة ما وصلت.
- «تصدير» ← «📤 أرسل ملف للبرنامج» ← بالواتساب لحاسبة المحل ← بالبرنامج: المخزون والجرد ← إدخال منتجات (جدول) ← «📂 فتح ملف» ← حفظ الكل.
  (يحتاج تحديث البرنامج 1.7.3)
- أو «تصدير»: ملف CSV بنفس الأعمدة + الباركود (ينفتح بالإكسل)، أو مشاركة بالواتساب، أو نسخ الأسطر.
- البيانات محفوظة على التلفون نفسه. صدّر القائمة قبل ما تمسحها أو تمسح بيانات المتصفح.

ملاحظة: الكاميرا تشتغل بس على رابط https (مثل Vercel). ما تشتغل إذا فتحت index.html كملف.
